# Changelog

## 0.2.1 — 2026-09-11

First release in this public repository. Includes post-v0.2.0 fixes and refactoring,
a loadable example, portable onboarding and browser checks, public cycle/spec maps,
contribution guidance, feedback templates, and CI.

See [release notes](docs/releases/v0.2.1.md) for features and known limitations.

## Earlier development

v0.1.0 introduced two-run LSS fitting and linear-gradient prediction. v0.2.0 added
independent candidate composition ranges and multi-segment programmes.
[Cycle maps and historical specifications](docs/roadmap.md) preserve that history.
The earlier tags belong to the original development repository.
