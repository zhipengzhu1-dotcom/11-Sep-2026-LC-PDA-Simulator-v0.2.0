# v0.2.1 — public feedback release

The first release in this public repository combines the v0.2 gradient-freedom
features with subsequent fixes and refactoring, portable setup, and public onboarding.

## Get started

```bash
git clone --branch v0.2.1 https://github.com/zhipengzhu1-dotcom/11-Sep-2026-LC-PDA-Simulator-v0.2.0.git hplcsim
cd hplcsim
uv run --locked --python 3.12 --extra app streamlit run streamlit_app.py
```

Install [uv](https://docs.astral.sh/uv/) first. Open <http://localhost:8501> and upload
[examples/three-peak-session.json](../../examples/three-peak-session.json) under
**Session** in the sidebar. Compare the predictions with the measured values in the
[example guide](../../examples/README.md).

## Features

- Fit per-peak LSS retention parameters from two scouting gradients.
- Explore a candidate's own starting/ending composition, ramps, and holds.
- Display predicted retention times, peak widths, adjacent-pair resolution, and chromatograms.
- See programme overlays, calibrated composition windows, and extrapolation diagnostics.
- Save inputs as JSON and reload them with a fresh fit; schema 1 sessions remain readable.

## Validation and limitations

Local validation: **867 tests passed** on Python 3.12.13; Ruff lint/format and strict
mypy passed. Chromium checks passed for example upload, candidate editing, session
save/reload, and pinned rows while scrolling. The CI workflow repeats the automated
gates on Linux.

The suite covers numerical consistency, published references, measured held-out runs,
and app behavior. The supplied three-peak example predicts approximately 13.871,
16.740, and 24.395 minutes against measured 13.787, 16.658, and 24.358 minutes.
Consult [SPEC.md, §10](../../SPEC.md) for acceptance thresholds and dataset scope.

- Multi-segment retention bench evidence rests on one peak in one two-segment run.
  **Multi-segment resolution has no validation claim.** Widths use the documented
  eluting-segment approximation.
- Some diagnostic tiers lack measured validation runs. Numerical checks do not replace
  that empirical evidence.
- Equivalent flat programmes can receive different regime badges if a peak outlives
  the programme: the closed-form path reports `isocratic_hold`, while the walker
  reports `post_gradient`. Retention time agrees. This known inconsistency remains
  explicitly covered in `tests/test_walker.py` (historical issue #100).
- Temperature is metadata. CSV import, automatic peak matching, ≥2-run regression,
  the resolution optimizer, and PDA spectral simulation are not features of this release.
- The app runs locally; this release does not provide a hosted demo.
